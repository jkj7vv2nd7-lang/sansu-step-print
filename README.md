# 算数つまずき診断＆補助プリント（プロトタイプ）

児童の誤答パターンから「つまずきの根本原因（前提単元の抜け）」を逆算し、その原因だけを練習できるA4縦1枚の補助プリントを生成する、教員向けツール。

## 構成

- `index.html` ― アプリ本体（単体HTML、CSS/JS内蔵、外部通信なし）
- `icon.png` / `icon-180.png` ― アイコン（プリント用紙＋3段ステップ＋虫めがね）
- `og.png` ― SNS共有時のプレビュー画像

## 起動方法

- ローカル確認：`index.html` をブラウザで開くだけで動作します（サーバー不要）。
  - 例：ファイルをダブルクリック、または簡易サーバーで `python3 -m http.server` → http://localhost:8000/
- 公開する場合：GitHub Pages に `index.html` と画像3点をそのまま置けば配信できます（リポジトリ作成と Pages 有効化は清水さんの操作）。

## 使い方（テスト手順）

1. 左パネル「1. つまずき診断」で、児童の様子に近いケースを選ぶ
2. ケースA・Dは分岐質問（どちらの様子に近いか）にも答える
3. 「根本原因の候補」と指導のポイントが表示される → 「この原因のプリントを作る」
4. 右にプリントが生成される（例題1問＋ガイドつき練習＋補助なし練習、数字は毎回ランダム）
5. 「2. プリントの見た目」で調整（マス目ON/OFF、文字サイズ、行間、問題数5/10/15、背景色、応援アイコン）
6. 「✅ 解答を見る」で丸付け用解答に切替。「🎲 数字を変える」で再生成
7. 「🖨 プリントを印刷」でA4縦1枚に印刷（背景色を出すには印刷画面で「背景グラフィック」をON）

## 検証済み（2026-11-14、ヘッドレスChrome実測）

- 6つの原因すべてで診断→生成→解答切替が動作（ページエラーなし）
- 印刷PDFのページ数：6原因 × 標準設定／最厚設定（特大・行間広め・15問）の全組み合わせで **A4縦1枚** を確認
- 1枚に収める仕組み：余白圧縮 → 練習の3カラム化 → 文字サイズの実寸縮小、の順に自動調整（CSS zoomは印刷に効かないためレイアウト自体を変える方式）

## プライバシー

- 児童の氏名等は入力欄自体がなく、保存もしません（なまえ欄は印刷後に手書き）
- 設定（見た目の調整）のみ端末内 localStorage に保存。サーバー送信は一切なし

## 拡張のしかた

- ケース追加：`DIAGNOSIS_DATA` に誤答パターンを1件追加し、原因を `CAUSES` に、問題生成を `GENERATORS` に登録するだけ
- 診断ロジックは `diagnose()` に分離済み。将来LLM推論へ差し替える場合は、この関数の返り値（原因オブジェクトの配列）の形を保つ

## 未確認・既知の制約

- 実機（清水さんのiPhone／実プリンター）での印刷確認は未実施
- 最厚設定（特大＋広め＋15問）では、1枚に収めるため文字が自動で小さくなります（極端な組み合わせでは約7.5px相当まで縮小）。通常の組み合わせでは等倍〜微調整で収まります
- フォントは端末にUD系フォント（BIZ UDPGothic等）がある場合に優先適用されます
